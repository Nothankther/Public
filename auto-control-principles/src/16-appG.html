G APPENDIX · CONCEPT CHECK

易混概念辨析 44 组Confusable concepts, side by side

选择题和判断题的失分，多半不是“不会”，而是“把两个词当成了一回事”。这一节把全书最容易混的 44 组概念并排放，只写区别和考法，不重复定义。

怎么用

遮住右两列，只看左边的两个概念，自己先说区别，再对照。凡是说不清“差在哪、什么时候会考”的，回到对应章节补一遍。带 ★ 的是近几届期末与考研反复出现的点。

#易混概念关键区别常见错误 / 考法
1被控对象 / 被控量对象是“设备或过程”，被控量是对象中要控制的“物理量”。把“液位”“炉温”写成对象。答题先问“控制谁”，再问“控制它的什么”。
2给定值 / 偏差给定值是目标；偏差是给定与反馈之差 $\varepsilon=r-b$。把给定值当成偏差。方框图中比较点的输出才是偏差。
3误差 / 偏差 ★误差在输出端：$e=r-c$；偏差在比较点：$\varepsilon=r-Hc$。单位反馈时二者数值相同。非单位反馈直接令 $e=\varepsilon$，导致稳态误差少乘 $H(0)$。
4开环 / 闭环有无反馈通路；闭环按偏差控制，精度高但可能失稳。说“闭环一定比开环好”。闭环的代价是稳定性与成本。
5负反馈 / 正反馈比较点相减为负反馈，相加为正反馈。控制中一般用负反馈。把正反馈一律判为“错误”。振荡器、零度根轨迹就是正反馈。
6恒值 / 随动 / 程序给定恒定 / 给定未知变化 / 给定按预定程序变化。把“随动”与“程序”混为一谈：前者规律未知，后者规律已知。
7线性 / 非线性是否满足叠加原理；非线性系统没有传递函数。对非线性系统套用 $G(\mathrm{j}\omega)$ 与劳斯判据。
8定常 / 时变微分方程系数是否为常数。把“非线性”与“时变”混为一谈，二者是不同维度。
9连续 / 离散信号在时间上是否连续；离散系统用 z 变换、差分方程。对采样系统直接写 $s$ 域传递函数，忽略保持器。
10传递函数 / 频率特性 ★$G(s)$ 是复变量 $s$ 的有理函数；$G(\mathrm{j}\omega)$ 是令 $s=\mathrm{j}\omega$ 后的正弦稳态描述。说“频率特性就是传递函数”。前者只对稳定系统、正弦稳态有意义。
11零点 / 极点零点使分子为零，影响响应形状与相位；极点使分母为零，决定模态与稳定性。认为“零点不影响稳定性”就完全无害——右半平面零点会限制带宽。
12首 1 型 / 尾 1 型 ★零极点形式 $K^*\prod(s-z_j)/\prod(s-p_i)$ 与时间常数形式 $K\prod(\tau s+1)/\prod(Ts+1)$。$K^*$ 与 $K$ 不换算就代稳态误差公式。换算：$K=K^*\prod|z_j|/\prod|p_i|$。
13系统型别 / 系统阶次型别是积分环节个数 $\nu$；阶次是特征方程最高次 $n$。把“二阶系统”说成“II 型系统”。二者完全无关。
14稳定性 / 稳态误差稳定性是前提；只有稳定系统谈稳态误差才有意义。不稳定系统仍用终值定理算出一个有限数，并当成答案。
15临界稳定 / 渐近稳定临界稳定：极点落在虚轴（或单位圆上），等幅振荡；渐近稳定：极点全在左半平面。把“不发散”当成稳定。临界稳定工程上按不稳定处理。
16结构不稳定 / 参数不稳定结构不稳定：缺项或系数符号固定，任何参数都无法稳定；参数不稳定：调参可稳定。对缺项系统仍列劳斯表求范围，得出一组“稳定条件”的空集。
17主导极点 / 偶极子 ★主导极点：靠近虚轴、决定动态的极点；偶极子：相距很近的零极点对，作用相互抵消。把“离虚轴近”误写成“离原点近”；把偶极子当成主导极点。
18欠阻尼 / 临界阻尼$0<\zeta<1$ 有超调；$\zeta=1$ 无超调，是“无超调前提下最快”的响应。说“ζ 越大响应越快”。ζ 超过 0.707 后，ts 反而增大。
19上升时间 / 调节时间上升时间：10%→90%（或首次到达稳态值）；调节时间：进入并保持在 ±5%（或 ±2%）带内。把“首次到达 1”当成“稳定在 1”。
20超调量 / 振荡次数超调量是峰值超过稳态值的百分比；振荡次数是调节时间内穿越稳态值的次数的一半。把振荡次数当成“峰个数”；穿越一次算半次。
21劳斯判据 / 赫尔维茨判据劳斯列首列变号；赫尔维茨算行列式主子式。二者等价。认为二者结论可能不同。只在一个算错时不同。
22静态误差系数 / 动态误差系数 ★前者只适用于阶跃/斜坡/加速度；后者把 $E(s)/R(s)$ 展开成级数，适用于任意输入。对 $\sin2t$ 仍用 $K_p,K_v,K_a$ 表，得出“误差为 0 或 ∞”的错误结论。
23根轨迹增益 / 开环增益 ★$K^*$ 对应零极点形式；$K$ 对应时间常数形式。$K=K^*\prod|z_j|/\prod|p_i|$。把 $K^*$ 直接代入 $e_{ss}=1/K_v$。这是第 4 章最高频失分点。
24180° / 0° 根轨迹负反馈用 180° 相角条件；正反馈用 0°。实轴规则：右侧零极点总数为奇数 / 偶数。正反馈仍按“奇数为轨迹”画，整条实轴画反。
25分离点 / 会合点轨迹离开实轴的点 / 回到实轴的点；都由 $\dd K^*/\dd s=0$ 给出。解出 $d$ 不检验是否在根轨迹上，把无效根写进答案。
26出射角 / 入射角从复数极点出发的切线方向 / 进入复数零点的切线方向。两套公式符号混用。出射角从极点出发，入射角从零点反推。
27参数根轨迹 / 广义根轨迹广义根轨迹包括参数根轨迹与零度根轨迹。把“参数根轨迹”当成“广义根轨迹”的同义词。
28相角裕度 / 幅值裕度 ★$\gamma$：在 $\omega_c$ 处距 $-180°$ 的余量；$K_g$：在 $\omega_g$ 处幅值还能放大的倍数。只算一个就判稳定。必须 $\gamma>0$ 且 $K_g>1$ 同时成立。
29剪切频率 / 交界频率$\omega_c$ 满足 $|G|=1$；$\omega_g$ 满足 $\angle G=-180°$。把 $\omega_c$ 叫“截止频率”又和带宽 $\omega_b$ 混用。
30最小相位 / 非最小相位最小相位：无右半平面零点、极点、延迟；幅频与相频一一对应。对含延迟环节的系统仍由 Bode 幅频唯一反推传递函数。
31开环频域指标 / 闭环频域指标开环：$\omega_c,\gamma,K_g$；闭环：$M_r,\omega_r,\omega_b$。前者用于设计，后者用于验算。用 $M_r$ 直接设计校正装置，绕过了开环裕度这一步。
32条件稳定 / 绝对稳定条件稳定：只在某一有界增益范围内稳定；绝对稳定：任意 $K>0$ 都稳定。把“条件稳定”判为“不稳定”。它只是在增益过大或过小时失稳。
33超前校正 / 滞后校正 ★超前：正相位、抬高 $\omega_c$、加快；滞后：负相位、压低高频、$\omega_c$ 左移、保相位。“滞后”不是“使系统滞后”，而是“让高频衰减、相位在别处变好”。
34串联校正 / 反馈校正串联在前向通道；反馈校正包围局部环节，能削弱被包围环节的参数变化。认为反馈校正一定提高精度。它主要改善稳定性和鲁棒性。
35前馈 / 反馈前馈按扰动或给定补偿，开环、不改变闭环稳定性；反馈按偏差，闭环。把前馈当成“另一种反馈”。前馈不能单独消除模型误差。
36采样定理 / 零阶保持器采样定理给出 $f_s\geq2f_{\max}$ 的条件；ZOH 是把采样值保持成阶梯的实现手段。以为“加了保持器就不需要采样定理”。保持器不能恢复丢失的高频信息。
37z 变换 / 脉冲传递函数z 变换是序列的变换；脉冲传递函数是零初始下输出/输入 z 变换之比。把连续传递函数直接令 $z=\mathrm{e}^{sT}$ 当脉冲传递函数，忽略保持器。
38w 变换 / z 变换w 变换是双线性映射 $z=(1+w)/(1-w)$，把单位圆内映射为 w 左半平面。把 w 变换当成“另一种 z 变换”。它只是为用劳斯判据而做的坐标变换。
39最少拍 / 无纹波最少拍：采样点有限拍到达并保持；无纹波：采样点之间也无纹波，需额外约束。认为“最少拍一定无纹波”。有纹波最少拍在采样点之间仍振荡。
40描述函数 / 相平面描述函数是频域近似（正弦输入、取基波）；相平面是时域几何（二阶系统轨迹）。用描述函数分析二阶非线性系统的全部初值行为；它只给自振的幅值与频率。
41自振 / 极限环自振是“无外输入时的持续振荡”现象；极限环是相平面上的孤立闭合轨迹。把“极限环”与“线性系统的等幅振荡”混为一谈：后者不是孤立的。
42可控 / 可观 ★可控：输入能否在有限时间影响全部状态；可观：输出能否反映全部状态。把“可控”当成“稳定”。可控性与稳定性无关。
43极点配置 / 观测器极点配置用状态反馈改变闭环极点；观测器用输出重构状态。认为观测器会改变闭环极点。按分离原理，二者可独立设计。
44LQR / LQGLQR：全状态可测时的最优状态反馈；LQG：LQR + 卡尔曼滤波，输出反馈。把 LQR 直接用于输出反馈而不加观测器/滤波器。
最后三条“万能判别”

① 只要题目出现“稳态误差”，先确认系统稳定、再确认用的是 K 还是 K*、最后确认输入阶次与型别；
② 只要题目出现“根轨迹”，先看负反馈还是正反馈（180° 还是 0°），再画实轴段；
③ 只要题目出现“离散”，先看采样周期是否满足采样定理，再把连续部分加 ZOH 化成 $G(z)$，不要直接代 $z=\mathrm{e}^{sT}$。
